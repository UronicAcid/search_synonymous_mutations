# Streamlit Application README

## Project Overview

This project is a Streamlit application designed to present our research findings and implement simple query and prediction functionalities. Users can conveniently learn about the main discoveries of our research and use the model for data predictions.

Here is the website: Hearing Silence (https://search-synonymous-mutations.streamlit.app/)

## Features

- **Research Presentation**: Showcases our research findings and related data.
- **Simple Queries**: Users can perform basic data queries.
- **Prediction Functionality**: Allows for model predictions based on input data.

## Requirements

Ensure you have the following dependencies installed in your environment:

- Streamlit
- pandas>=2.0.0
- catboost>=1.1.1

You can use the `requirements.txt` file to install all dependencies:

```bash
pip install -r requirements.txt
```


## Using the app via the terminal

The Streamlit app can be run locally via the terminal.
```bash
streamlit run app.py
```
